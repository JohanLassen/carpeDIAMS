# carpeDIAMS: DIA to pseudo-DDA spectra

Turns DIA (bbCID) acquisitions into pseudo-DDA spectra by correlating
MS1 elution with MS2 fragment elution across many samples. Produces an
MGF that downstream library/annotation tools consume.
